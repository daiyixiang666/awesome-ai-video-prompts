投稿

看到好作品，或者自己做了得意的作品，都欢迎推荐。每部投稿都会人工筛选，入选后署名并链接原作者。

收什么

  • 视频：AI 视频模型生成的单条短片，60 秒以内（短片加制作讲解也可以）。
  • 图片：AI 图片模型生成的作品，偏好有艺术感的。
  • Coding：大模型写代码做出的作品（three.js、WebGL、shader…），需写明用的 AI 工具。

不收什么

搬运、广告、梗图、擦边，以及看不出审美和方法的作品。

怎么投

用 GitHub 投稿

没有 GitHub 账号？把原作链接、作者、用的模型（和公开的提示词，如有）发邮件到 yixiang@umich.edu。

作品版权归原作者所有，本站只做索引、标注与提示词整理，并链接到原帖。如权利人认为收录不当，请发邮件至 yixiang@umich.edu（或在 GitHub Issues 留言），我们核实后第一时间下架。
