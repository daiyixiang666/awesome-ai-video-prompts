Submit

Found a great piece, or made one you are proud of? Recommend it. Every submission is screened by hand; selected works credit and link the original creator.

What we take

  • Video: single clips from AI video models, up to 60 s (a clip plus a how-it-was-made breakdown is fine).
  • Images: work from AI image models, artistic work preferred.
  • Coding: works an LLM built by writing code (three.js, WebGL, shaders…); name the AI tool.

What we don't

Re-uploads, ads, memes, sexual bait, and work without clear taste or craft.

How to submit

Submit on GitHub

No GitHub account? Email the link to the original post, the creator, the model (and the prompt, if published) to yixiang@umich.edu.

All works belong to their creators; this site only indexes and annotates them and links to the original posts. Rights holders who want a work removed can email yixiang@umich.edu (or open a GitHub issue) and we will take it down promptly.
